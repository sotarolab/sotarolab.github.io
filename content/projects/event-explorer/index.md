Characterizes an incoming weather extreme in terms of its climatological rarity — before it happens. Event Explorer takes a GFS or ECMWF forecast, compares it gridpoint-by-gridpoint to the ERA5 1991–2020 climatological baseline, and answers: if this forecast verifies, how rare would this event be? After the event passes, ERA5 reanalysis swaps in for the same analysis to verify the forecast and build a growing library of documented extremes.

Current focus: heat waves in the Mid-Atlantic / DC region.
