Named after the coastal fog of northern Chile — shaped by the Humboldt Current and the interplay of large-scale dynamics and local boundary-layer physics — this project diagnoses and corrects probabilistic National Blend of Models (NBM) Tmax forecast errors for coastal Southern California.

Live forecast verification dashboard built with Dash, backed by a Postgres database ingesting 5-minute METAR observations, deployed on Render with automated CI via GitHub Actions.
